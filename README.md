# 🛒 NovaCommerce API

API RESTful desenvolvida em **ASP.NET Core (.NET 8)** para simular um sistema de e-commerce, com autenticação JWT, CRUDs e deploy em nuvem.

---

## 🚀 Tecnologias Utilizadas

- C#
- ASP.NET Core 8
- Entity Framework Core
- SQL Server
- JWT Authentication
- Docker
- GitHub Actions (CI/CD)
- Swagger (OpenAPI)

---

## 📌 Funcionalidades

- Autenticação de usuários com JWT
- Cadastro e login de usuários
- CRUD de Produtos
- CRUD de Categorias
- CRUD de Autores
- Documentação interativa com Swagger
- Build e deploy automatizados
- API publicada em ambiente cloud
